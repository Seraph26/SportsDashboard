Sports Dashboard

How to run:
1. Make sure Node.js is installed on your computer.
2. Double-click start-dashboard.bat
3. Your browser should open automatically at http://localhost:3000

Notes:
- This app needs internet access to load live sports data.
- If the browser does not open, manually go to http://localhost:3000
- Keep the command window open while using the app.
- To stop the app, close the command window.
